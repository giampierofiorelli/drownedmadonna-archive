Date: Tuesday, July 22 @ W. Europe Daylight Time

This is an old rumour. Madonnarama revealed it many months ago. It was rumoured that Jessica Simpson recorded a track called "Forbidden Fruit", which is probably a track written and produced by Madonna and Mirwais, rejected from "American Life" album because it sounds too similar to "Die Another Day" and doesn't fit the theme of the album.

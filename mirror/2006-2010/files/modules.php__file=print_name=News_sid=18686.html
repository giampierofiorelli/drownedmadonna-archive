The Sun证实：麦当娜新专辑明年推出
Date: Tuesday, September 25 @ 03:55:03 CEST
Topic: Newspapers

    

  英国报刊The Sun目前证实了DrownedMadonna网站发布的新闻，称麦当娜的新专辑将在明年推出，并且避免和凯莉-米洛在榜单上竞争。凯莉-米洛将是年底最受关注的歌手。

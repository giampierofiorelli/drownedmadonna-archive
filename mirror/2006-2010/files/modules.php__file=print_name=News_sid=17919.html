''Like A Virgin'' par Julien: Comment Madonna peut faire de vous une Star!
Date: Sunday, April 22 @ 17:20:49 CEST
Topic: Magazines

Interviews, couverture de magazines... Depuis que Julien a chanté "Like A Virgin" à l'émission française "Nouvelle Star" sur la chaîne française M6, il est dans tous les médias français. Mais, comme indiqué sur la chaîne française W9, sa version de "Like A Virgin" était une reprise créée par le chanteur américain Richard Cheese. Julien lui-même l'admet sur W9 et dans les interviews avec les magazines français. Pour vous donner une idée de l'impact que cette version de "Like A Virgin" a en France, regardez la presse française ci-dessous.

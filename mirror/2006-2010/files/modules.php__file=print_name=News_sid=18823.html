三星U600推出麦当娜版! 通体镶施华洛世奇水晶
Date: Thursday, October 18 @ 10:59:43 CEST
Topic: Merchandising

  三星的U600也就是在我国发行的U608。这款手机是三星07年的重点机型之一，不仅拥有全面的功能，在外形设计上更是下足了功夫。如果评选07年最漂亮的手机，三星U600应该占据一席之地的。最近这款手机又有新闻传出，一张镶满了施华洛世奇水晶的三星U600照片曝光于网上。U600本身较薄，镶满了水晶后机身显得厚实了不少，机身的边框和上盖大部分都进行了水晶镶嵌，并以橘黄色为主色调。机身整体显得华丽了不少。不过我们不禁纳闷，镶嵌水晶后，用户使用上盖的触感按键会不会有影响呢？

  除了镶嵌水晶外，这款三星U600还有一个特别之处。在这款手机的后背，有一副同样是采用施华洛世奇水晶的拼接画，不同颜色的水晶组成了一副流行天后麦当娜的头像。也正是因为这样，网上有人将这款手机成称为“麦当娜”版。对于这款镶满了水晶的麦当娜版的出处我们暂时还不清楚，目前三星也没有官方声明说将推出特别版的U600。

  生活中喜欢装饰自己手机的人不在少数，相信我们周围总有些朋友喜欢在自己手机上装饰些小水钻之类的东西。如今有一款镶满了水晶的时尚手机，不知道会不会有人喜欢呢？PConline手机频道将为大家持续关注这款手机和三星的最新动态。

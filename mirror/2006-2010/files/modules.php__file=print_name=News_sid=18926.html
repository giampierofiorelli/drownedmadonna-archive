DrownedMadonna独家连线圣德西电影节组织者
Date: Tuesday, November 06 @ 15:41:57 CET
Topic: Movies

  由于有传言麦当娜将在明年的圣德西电影节上放映自己的新纪录片，DrownedMadonna就此问题独家连线电影节组织者。 

  组织方表示：“我们目前还不能确定或否认任何有关明年电影节的传言。”

  “我们将在11月29日，30日公布电影节上将放映的长篇电影名单，将放映短篇电影名单将在下周公布，也许是星期三。”

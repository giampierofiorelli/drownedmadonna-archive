[传言]麦当娜天价跳槽详细信息
Date: Thursday, October 11 @ 17:32:18 CEST
Topic: Gossip

  洛杉矶路透社消息，麦当娜将离开老东家华纳公司，与娱乐促进公司Live Nation Inc.签署10年的唱片与演唱会合约，报酬高达1.2亿美元（约58.8亿英镑）。华尔街日报也报导了该消息。

  报道称，麦当娜将与新东家合作，推出三张唱片，开展巡演，销售一切其名下商品。

  今年49岁的麦当娜，在出道时就与华纳公司合作，开始其漫长的事业。

  目前Live Nation方面拒绝回应。麦当娜与华纳方面也没有做出回应。

  来源：路透社

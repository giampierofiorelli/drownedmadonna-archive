《Madonna Icon》荷兰上市
Date: Tuesday, October 16 @ 05:32:47 CEST
Topic: Books

  由作家Lucy O'Brien完成的麦当娜新传记书籍《Madonna Icon》将在荷兰上市了。

  该书将被译为荷兰语发行，并在荷兰官方歌迷会的建议下，用《Madonna Het Icoon》作为书名。

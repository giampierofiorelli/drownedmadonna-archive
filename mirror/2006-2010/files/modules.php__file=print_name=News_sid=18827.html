Ari Gold谈论与麦当娜的安息日晚餐
Date: Thursday, October 18 @ 15:45:57 CEST
Topic: Kabbalah

  在之前的报导里，我们提到了麦当娜与其他名人朋友一起在纽约享用犹太教安息日晚餐，其中包括歌手Ari Gold. Ari Gold本人也在一封写给朋友与歌迷的信件里谈论了那次晚餐，这封信被发布在他的官方Myspace上，下面是一段摘抄：

  上个礼拜五的晚上我去拉卡巴拉教中心。我被中心的一位导师Michael Moskowit邀请赴宴，我在很早前就认识了Michael，他与他的夫人的确是热情周到的主人。Micheal告诉我，当晚我是男性特殊客人，而麦当娜是女性特殊客人。我们一边庆祝卡巴拉中心建设人妻子Karen Berg的生日，一边迎接安息日到来后的新的一个月。当我默默地站在那里做祷告的时候，我不得不分神地去注意麦当娜，她是我很小的时候就开始崇拜的偶像，我一直梦想着见到她。我知道这样分神是不对的，我只好静下心来，想着自己能够和麦当娜在多年以后一起做着一样的祷告，我想是神让我完成了自己的夙愿。

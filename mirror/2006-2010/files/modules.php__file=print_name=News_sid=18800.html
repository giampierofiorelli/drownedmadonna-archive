著名摄影师Steven Klein不满汤姆-克鲁斯工作态度
Date: Tuesday, October 16 @ 06:28:23 CEST
Topic: Interviews & Statements

  要和好莱坞明星汤姆-克鲁斯一起共事非常有难度，特别是拍摄写真时。

  著名时尚摄影师，麦当娜多年合作伙伴Steven Klein目前表示，为汤姆-克鲁斯拍摄新一期《W》杂志的写真，简直是“不可能的任务”。

  Steven Klein一直以来对于合作过的伙伴都赞赏有嘉，而目前却被透露抱怨汤姆-克鲁斯，不满其工作态度。据《纽约日报》报导：“很显然，和汤姆-克鲁斯一起工作使人感到很烦恼。Steven还表示，当麦当娜工作时，她言出必行，行事果断。可他实在不喜欢和汤姆-克鲁斯一起工作。”

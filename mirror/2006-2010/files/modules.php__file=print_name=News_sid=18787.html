更多《I Am Because We Are》细节介绍
Date: Sunday, October 14 @ 12:19:31 CEST
Topic: Movies

  DrownedMadonna被告知，《I Am Because We Are》并不只是在马拉维录制完成的。  

  实际上，卡巴拉中心还制作了另外一部纪录片，有一位美国女性导演执导。

  而《I Am Because We Are》是麦当娜的个人计划。导演Nathan Rissman为麦当娜执导这部纪录片已经有好几个月。Nathan Rissman和另外一位朋友代表麦当娜多次远赴马拉维，Nathan Rissman在马拉维呆了好几个月，和当地人们熟稔。他在当地除了拍摄纪录片外，还亲身照顾了马拉维儿童。

  而麦当娜的马拉维之行为她收集了很多制片的感性材料以及片断。

  同我们曾报导的一样，“影片中反映了能够帮助马拉维儿童的办法之一，经过麦当娜的实践，就是Spirituality for Kids以及Rasing Malawi慈善机构。”

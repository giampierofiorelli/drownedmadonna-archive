约翰-马尔科维奇回忆与麦当娜拍摄影片《影与雾》
Date: Saturday, November 03 @ 02:13:45 CET
Topic: Magazines

  约翰-马尔科维奇登上了最近一期的法国杂志《TRANSFUGE》的封面，该杂志中同时包含了长达14页的访谈。在这次访谈中，约翰-马尔科维奇回忆到了他在1992年与麦当娜以及米亚·法罗共同拍摄伍迪·艾伦的影片《影与雾》。

  杂志中含有一张四人正在拍摄过程中的工作照片。

麦当娜伴舞Raistalla获Digifestival.net 2007大奖
Date: Monday, September 24 @ 16:18:14 CEST
Topic: Awards

    麦当娜在2004巡演中的伴舞Raistalla，今日将赴意大利佛罗伦萨接受来自DigiFestival的大奖。感谢大家的支持，Raistalla获得的是“Best Absolute Audience Winner"。

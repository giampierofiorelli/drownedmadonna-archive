英国太阳报：麦当娜获得大卫正式监护权
Date: Tuesday, October 23 @ 15:57:38 CEST
Topic: (Private) Life

  以下新闻消息来自The Sun：

  麦当娜比自己预期里早5个月获得了养子大卫的正式监护权。

  马拉维高级法院将在下个月进行对麦当娜临时监护的审查。

  而原计划里，授予麦当娜正式监护权的时间是在明年4月左右。麦当娜的养子大卫，现年两周岁，已经与麦当娜的丈夫，子女在伦敦共同生活了一年。

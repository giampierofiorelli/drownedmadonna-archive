《I Am Because We Are》简介
Date: Saturday, October 13 @ 08:12:19 CEST
Topic: Movies

  麦当娜的新纪录片《I Am Because We Are》目前出人意料的在以色列的一次儿童慈善活动中首映。

  相关人员向DrownedMadonna透露：这部电影非常美丽且感人，影片把焦点放在了马拉维贫穷，痛苦的儿童身上。影片反映了艾滋病对马拉维儿童造成的影响，大批儿童因艾滋病失去双亲，只得露宿街头。

  最后，《I Am Because We Are》反映了Spirituality for Kids以及Rasing Malawi儿童慈善机构是如何带给他们希望的光芒，给他们以机会，改变自己未来的生活。

华纳唱片公司回应麦当娜转会
Date: Friday, October 19 @ 04:03:17 CEST
Topic: Music

  华纳唱片公司对麦当娜转会作出回应：“我们为麦当娜的未来计划感到高兴。她是我们的时代里当之无愧的顶尖艺人。我们将在明年推出她的新专辑，对此，我们感到很兴奋。我们很荣幸地拥有麦当娜在过去25年艺术生涯里的歌曲版权，在日后长期时间里，我们将仍然持有对这些歌曲的使用权。我们华纳唱片公司的所有人员，衷心感谢麦当娜在过去的时间里与我们的合作。”

  Live Nation同时也表示，随着麦当娜的加入，将为麦当娜开设Artist Nation分部，专门用来处理艺人的唱片，周边产品，音乐会门票，赞助，市场以及其他项目。

麦当娜伴舞Sofia接受采访谈论麦当娜
Date: Thursday, October 04 @ 02:27:13 CEST
Topic: Interviews & Statements

  Sofía Boutella目前为了自己代言的Nike女性运动系列来到了西班牙。

  她为西班牙选秀节目《超模2007》的比赛选手们上了一节舞蹈课，并为他们提供了一些建议。

  在接受杂志《Telva》的采访时，她谈到了麦当娜：

  “太棒了。的确是非常辛苦的工作，但是却帮助我更加了解了自己，我很喜欢麦当娜，因为她工作时总是精力充沛。”

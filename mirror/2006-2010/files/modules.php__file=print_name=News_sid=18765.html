麦当娜马拉维纪录片《I Am Because We Are》
Date: Saturday, October 13 @ 03:43:10 CEST
Topic: Movies

  以下新闻来自Rosie.com：

  麦当娜在纽约去看了哪部电影的私人放映会？

  她的新纪录片《I Am Because We Are》，强大而令人惊讶的作品。

  据悉，该纪录片的名字为Desmond Tutu的名言。（Desmond Tutu是南非开普敦的一位大主教）

  正如班图精神中所强调的：谁都不是一座孤岛,自成一体。“I Am Because We Are”表达了我们都是连结在一起的，我们不能脱离团体而成就自己。一个人的健康与信仰在脱离团体后将不能存在。

  在收听完毕后，我们可以总结出来一些新的协议细节，比如：

  1 麦当娜将在两年以内开展新的世界巡演。

  2 麦当娜将在加盟Live Nation后的两年（最迟不过三年内）推出自己的新专辑。

 

  尽管在前面提到了，麦当娜将在两年以内开展新的世界巡演。之后又被问及麦当娜是否会在新专辑推出后就开始巡演。Live Nation表示，根据麦当娜的情况，她已经在2001，2004以及2006年分别为自己的专辑开展世界巡演，所以为这次的新专辑巡演也很有可能。

  Live Nation还期望在未来10年里将举办4次麦当娜的世界巡演。

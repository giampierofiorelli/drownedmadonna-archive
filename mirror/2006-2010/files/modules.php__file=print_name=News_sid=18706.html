麦当娜获入选明年摇滚名人堂提名
Date: Friday, September 28 @ 03:27:45 CEST
Topic: Awards

    

  入选2008摇滚名人堂的艺人名单，今天被正式公布。

  麦当娜，野兽男孩（the Beastie Boys），戴唯克拉克五人组（the Dave Clark Five），伦纳德·科恩（Leonard Cohen），非洲邦巴塔（Afrika Bambaataa），约翰-麦伦坎普（John Mellencamp），历险乐团（the Ventures），当娜-桑莫（Donna Summer），席克（Chic）被提名为入选下届摇滚名人堂的艺人。

  麦当娜和野兽男孩的入选，也是他们第一次获得入选资格后的第一次入选。据悉，一位能入选摇滚名人堂的艺人必须要在入选年的25年前发行自己的首支单曲或专辑。所以今年入选的艺人必须不得迟与1982年发行自己的处女作。而麦当娜的首支单曲《Everyboay》和野兽男孩的朋克EP《Polly Wog Stew》正是发行在1982年。

  最后将筛选出5位艺人正式入主摇滚名人堂。名单将在2008年1月公布。而颁奖典礼将在2008年3月10日举行。所有进入摇滚名人堂的艺人都将在滚乐名人堂博物馆获得属于自己的位置。

  以下是这份公文提到关于麦当娜的部分：

  在1982年后，机遇的大门就向麦当娜敞开了。在纽约的各俱乐部驻唱跳舞的麦当娜，与SIRE公司签约成为职业歌手，使得她独特的形象与概念席卷电台，俱乐部，并造就了第一批MTV观众。她凭借7支冠军单曲，3张冠军专辑以及17支Top 10热门单曲成为八十年代最成功女性艺人。麦当娜不仅是独特的音乐人，也是狂野不羁的舞台表演艺术家。从1984年的首支冠军单曲《Like A Virgin》到最近两年的Confessions音乐系列，麦当娜依旧是最强大的音乐人之一。

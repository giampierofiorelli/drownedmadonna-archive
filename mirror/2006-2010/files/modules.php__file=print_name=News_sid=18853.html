  麦当娜

  这位物质女郎曾在2006世界巡演中要求所有场地不得开冷气，以次来保护自己的嗓音。

  麦当娜在外演出时，还要求自己使用的所有化妆间里配备一个全新的，从未使用过的洗手间。

  麦当娜不酗酒，她要求只饮用卡巴拉教的圣水。

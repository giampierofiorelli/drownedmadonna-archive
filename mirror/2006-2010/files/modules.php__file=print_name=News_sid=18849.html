盖里奇父亲的担忧
Date: Tuesday, October 23 @ 15:17:24 CEST
Topic: (Private) Life

  盖-里奇的父亲约翰最近表示自己非常担心儿子的婚姻，因为儿子最近和麦当娜很少见面——他们分别身处大西洋各一边。

  但他现在应该会欣慰不少，因为盖告诉他父亲，表示自己将要搬去纽约，和麦当娜在一起。麦当娜正在纽约为自己的一部关于马拉维的新纪录片而工作。

  在上个周末麦当娜养子大卫的两周岁生日派队上，约翰告诉一个朋友：“这是盖这么长时间来与麦当娜的第一次见面。以前麦当娜和她的孩子们一直在纽约，而盖却一直在伦敦。”

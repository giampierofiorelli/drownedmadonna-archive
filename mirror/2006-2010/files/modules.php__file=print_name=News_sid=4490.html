Great Ormond Hospital launches Children Book Competition!
Date: Sunday, September 19 @ 12:43:56 CEST
Topic: (Private) Life

For all would-be authors, Great Ormond Street Hospital , the one visited by Madonna and Lola  last August, has launched a competition for a follow up to the children's classic Peter Pan by J.M. Barrie. Entries need to be submitted (synopsis and sample chapter) via publishers and agents by 31st January 2005, so get writing now!

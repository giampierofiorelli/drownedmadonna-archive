[传言]麦当娜欲购特拉维夫豪宅
Date: Tuesday, September 25 @ 03:48:43 CEST
Topic: (Private) Life

  之前在以色列同众多卡巴拉教友迎接犹太教新年的麦当娜，最近被报道称有意购买特拉维夫北部的豪华居所。该公寓底价为1百万美元。另外句媒体报道，史蒂文·斯皮尔伯格也将参与购买。在麦当娜两年前造访以色列时，当地媒体就曾报道，称她想在罗什平纳购买公寓。

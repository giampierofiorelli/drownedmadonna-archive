吉尼斯世界纪录刷新麦当娜成绩
Date: Thursday, September 27 @ 02:19:56 CEST
Topic: Press Release

  一份来自官方的吉尼斯世界唱片纪录公文提到了麦当娜最近在世界范围内的唱片成绩，并通过吉尼斯纪录认证。这份子公文发表在2008年新版吉尼斯纪录上。以下是内容摘要：

  新版吉尼斯纪录在2007年9月28日发表，其间纪录了女歌手之间的激烈竞争，如麦当娜凭借2006年的巡演Confessions Tour击败雪儿(Cher)，获得史上平均收入最高的巡演。（也成为史上最卖座的女歌手巡演）有一百二十万歌迷观看了麦当娜的Confessions Tour巡演，预计总收入达到一亿英镑，平均每场收入为一百六十万英镑！

  流行乐女王的成就不只如此，她凭借自己的第九张成功的专辑《Confessions on a Dance Floor》获得“最多冠军专辑”纪录，此前纪录保持者为凯特-布什（Kate Bush）。

麦当娜在洛杉矶为女儿庆祝生日
Date: Tuesday, October 16 @ 06:17:34 CEST
Topic: (Private) Life

  麦当娜在离开了纽约后，并没有如人们所意料的那样去了伦敦，而是去了洛杉矶，为女儿庆祝其11岁的生日。

  为了庆祝女儿卢尔德11岁生日，麦当娜带着女儿先到一间名为“One”的SPA享受了六小时护理。接着又前往Ristorante de Georgio Baldi餐馆吃饭。目击者称，这对母女当天的衣着也相当配合。

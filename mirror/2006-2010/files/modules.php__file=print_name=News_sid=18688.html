说唱歌手阿肯期待与麦当娜带来全新震撼
Date: Tuesday, September 25 @ 05:16:53 CEST
Topic: Interviews & Statements

  目前MTV简短地报道了说唱歌手阿肯（AKON）目前正在与麦当娜合作她最新专辑的新闻。

  在采访中，阿肯表示目前没有同麦当娜一起开始录制工作，不过很期待与麦当娜的合作将在年底给全球带来新的震撼。

  （DrownedMadonn特别提示：麦当娜新专辑将在明年推出。）
